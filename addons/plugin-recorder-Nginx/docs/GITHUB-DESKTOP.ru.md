# Публикация через GitHub Desktop, Windows 11

1. Скачайте ZIP, распакуйте в отдельную папку. Это новый проект, а не архив состояния сервера.
2. В локальном клоне `matrix-element-call-recorder` создайте ветку, например `nginx-recorder-v3`. Через Проводник скопируйте содержимое проекта в `addons/plugin-recorder-nginx-v3/`. Не перезаписывайте прежний addon до приёмки новой версии.
3. В GitHub Desktop проверьте diff. Должны присутствовать только исходники, тесты и документация. Не добавляйте реальные `answers.json`, `.env`, профили, SQLite, записи, сертификаты или серверные журналы.
4. В описании commit укажите `Nginx recorder plugin v3 release candidate; monolith observer pinned`. Выполните Commit, затем Push origin / Publish branch.
5. Откройте pull request. Сохраните маркировку RC и приложите `VALIDATION.md`; не называйте сборку production-tested.
6. После приёмки чистой установки и реального звонка обновите `VALIDATION.md`, `VERSION`, README и контрольные суммы. Внутренняя версия установщика также должна быть обновлена согласованно.

Сборочный архив уже обезличен: примеры используют `matrix.example.org`. Публикация GitHub из этой сессии не выполнялась. Рабочие конфигурации вашего тестового сервера не заменялись обезличенными примерами.
