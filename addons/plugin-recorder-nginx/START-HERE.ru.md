# С чего начать (v3.1.0)

Три шага, ничего не меняя на сервере, кроме шага 3.

## 1. Проверить

```bash
cd plugin-recorder-nginx
cp answers.example /root/answers.env
chmod 600 /root/answers.env
nano /root/answers.env          # почти всегда достаточно DOMAIN="..."

bash install.sh --check /root/answers.env
```

`--check` работает только на чтение. Если есть блокеры — код возврата `2`,
и под каждым блокером напечатана готовая команда исправления. Пока блокеры
не устранены, `--install` откажется работать (обход: `FORCE_INSTALL="true"`,
осознанно).

## 2. Установить

```bash
bash install.sh --install /root/answers.env
```

Установщик сам: определит контейнеры Element Web / Synapse / Element Call,
соберёт образы контроллера, портала, публикатора и worker'а, поднимет стек,
сгенерирует конфиг nginx, зарегистрирует UI-модуль в Element Web и прогонит
дымовые проверки.

Первый запуск собирает образы — 5–15 минут, в зависимости от канала.

## 3. Опубликовать наружу

По умолчанию плагин слушает `127.0.0.1:18085`. Добавь на своём фронт-прокси
(Traefik, nginx, Caddy — без разницы) два маршрута на этот адрес:

```
/recording/   ->  http://127.0.0.1:18085
/recordings/  ->  http://127.0.0.1:18085
```

Важно: `proxy_buffering off` (или аналог) для `/recordings/`, иначе скачивание
больших MP4 будет идти рывками.

Если фронт — это nginx, и ты хочешь, чтобы плагин встроился в него сам:

```bash
# в answers.env
NGINX_MODE="external"
bash install.sh --install /root/answers.env
```

В этом режиме установщик добавит ровно одну строку `include` в `server{}`
твоего домена на `:443` и откажется это делать, если подходящий `server{}`
не единственный (тогда напечатает строку для ручной вставки).

## 4. Включить кнопку

Открой Element Web, обнови страницу. В заголовке комнаты, где у тебя
power level ≥ 50, появится кнопка записи.

Проверить цепочку целиком в любой момент:

```bash
bash tools/verify.sh http://127.0.0.1:18085 /root/answers.env
```

Если что-то не работает:

```bash
bash install.sh --doctor /root/answers.env
```

`--doctor` показывает каждое звено отдельно: контроллер напрямую, контроллер
через nginx, контроллер изнутри nginx-контейнера, worker, общую сеть. Место
разрыва видно сразу, без гадания по логам.

---

## Что этот установщик НЕ делает

- Не разворачивает Matrix, Synapse, Element Web, Element Call, LiveKit.
- Не настраивает Traefik и не требует его наличия.
- Не правит чужие `server{}` без явного `NGINX_MODE="external"`.
- Не удаляет записи и E2EE-профиль бота при `--uninstall`.
- Не понижает требования E2EE и не повышает права в комнатах.
