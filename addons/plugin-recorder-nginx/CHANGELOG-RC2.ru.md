# 3.0.0-rc2 — исправление приложенного RC1

## Подтверждено в архиве и журнале 2 ноября 2026

1. `check()` передавал неопределённый `inspect` в конструктор Preflight. Это не модуль стандартной библиотеки; `import inspect` не исправляет код. Неиспользуемый параметр удалён из интерфейса.
2. `installer/preflight.py` не имел точки входа: прямой запуск завершался с кодом 0, не проверив ничего. Добавлен main, три публичные точки входа используют один check.
3. Два разных dependency probe: отдельный preflight без /app и повторная проверка installer с /app. Первый мог не найти существующий puppeteer-core. Теперь один probe с явным workdir /app и проверкой ESM import.
4. Missing vhost после зарегистрированного FAIL повторно читался без проверки и приводил к FileNotFoundError. Теперь отчёт собирается без traceback.
5. Repair считал свои аккаунт, профиль и порты чужими. Исправлено с проверкой provenance и PID; неизвестный listener по-прежнему блокируется.
6. Пулы POOL_WORKERS не проверялись. Добавлен JSON-разбор и сравнение полного MXID, без ложного конфликта одинаковых localpart разных homeserver.
7. PATH docker-shim мог показывать успешный docker run, а Compose запускал другой runtime без инъекций. Теперь один явный реальный Docker CLI, shim из PATH обходится без удаления.
8. Сырые ошибки скрывались слишком обобщённо. Добавлены код возврата, стадия probes и адресные подсказки без раскрытия stderr/env.
9. RC1 SHA256SUMS включал себя, а архив содержал pycache. RC2 исключает оба и проверяет каждый файл после упаковки.

## Не выдаётся за установленную причину
Последний `installer exit=1` в журнале не содержит соответствующего stderr. Поэтому RC2 исправляет воспроизводимые дефекты, но не приписывает этому последнему отказу единственную доказанную причину. Ошибки окружения — отсутствие реального Element config, образов, рабочего puppeteer-core, действительного vhost — нельзя лечить stub-образами.

Вызов `bash -c SCRIPT check /usr/bin/chromium` сам по себе корректен: check — $0, Chromium — $1. Создание /app/check было ненужным обходом, а не исправлением.

## Что не менялось
Эталонный observer монолита и его E2EE/FFmpeg логика; runtime worker/backend/publisher (кроме версии UI). Никаких миграций бота, профиля, power levels или смены серверных паролей. GitHub не изменялся из этой сессии.
