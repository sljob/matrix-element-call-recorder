# Исправления 3.0.0-rc3

Основание: вложенный rc2_dev_bundle_20261103171350, исходный вложенный RC2 с SHA256 b2da3d4088033662b4fdcc60bfb23e839d9848fd0f703f819a7e1f693e700b4b. Правки сделаны к этому архиву, а не поверх многочисленных серверных fix-скриптов.

## Подтверждённые проблемы

1. Модуль проекта находится в ui/index.js. Поиск static/record-button.js в сторонних серверных fix-скриптах неверен; такую загрузку добавлять не нужно. Вставка ES-модуля обычным script-тегом также не заменяет Module API Element.
2. В приложенных журналах location-snippet включён вне server-блока. Nginx сообщает location directive is not allowed here. Эти внешние изменения RC3 не исправляет автоматически: сначала восстановите корректный Nginx из резерва или снимка, иначе preflight остановится на nginx -t.
3. При umask 077 создание release.mkdir(mode=0755) само по себе даёт 0700. Предыдущий установщик исправлял дочерние файлы, но не сам release. Исправлено явным chmod(0755); добавлен тест с настоящим umask 077 и тест чтения JS настоящим Nginx worker.
4. Старый regex-разбор server-блока не различал комментарии, кавычки, переменные и вложенность. Новый структурный разбор вставляет include только прямым потомком выбранного TLS server на 443. Проверяется загруженность файла через nginx -T, дублирующий server_name и конфликтующие locations. Неоднозначный конфиг не редактируется.
5. В dev bundle recorder-p44 отсутствует, Synapse/LiveKit на указанных адресах недоступны, а 8765/8788 заняты mock. Пользовательский custom-preflight помечал критические ошибки как WARN. RC3 штатный preflight блокирует отсутствие образа, неправильный Matrix versions, Call HTML/config и LiveKit TCP. Порты проверяются по владельцу при repair, не по ответу mock /health.
6. После reload проверяются реальные HTTPS module bytes, опубликованный Element config и идентичности backend/worker. Несовпадение вызывает откат конфигурации вместо ложного Installed. Проверка требует корректных DNS/TLS; TLS не отключается.
7. Backend и worker health включают service/pid. Processing после аварии без успешно опубликованного .done не удерживает worker вечно занятым: состояние error, исходный файл сохранён.

## Не изменялось

Эталонный vendor observer, его SHA256, Matrix login/E2EE/медиа и FFmpeg capture сохранены. Docker image не строится, не заменяется заглушкой и не скачивается автоматически. Профили, учётки, права комнат и посторонние Nginx-конфиги не удаляются/не сбрасываются.

## Граница проверки

Исправлены воспроизведённые дефекты установщика/раздачи UI. Это не доказательство записи настоящего E2EE-звонка: Docker daemon и реальная Matrix-платформа в среде сборки недоступны. Команда tests содержит mock Matrix для авторизации, но тест Nginx HTTPS/file permissions и FFmpeg/Node lifecycle выполняется реально.
